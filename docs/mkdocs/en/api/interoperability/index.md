# OpenQASM & Qiskit

OpenQASM and Qiskit give you two ways to bring an existing circuit into FatQat.
The interface to use depends on how the circuit is written and where you want to
read the results.

- [OpenQASM](openqasm.md) covers import from source text or a file and export to
  OpenQASM 2 or 3.

- [Qiskit](qiskit.md) covers conversion to a FatQat program and running a circuit
  through the Qiskit backend API.

The [connection guide](../../guide/interoperability.md) runs the same measured
circuit through these routes.
